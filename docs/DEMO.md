# Short presentation guide

1. Explain the problem: students need a simple route between campus places.
2. Select UVPCE New Building and Nescafe; show the blue route and map controls.
3. Change the start to MBA Building to demonstrate a different route.
4. Show `campus_map.json`: names and paths are separate from the algorithm.
5. Show the small loop in `RouteFinder.kt` and explain shortest path in plain words.
6. Show `CampusMapView.onDraw()` and explain shapes, paths, route and markers.
7. Be honest about the challenge: screenshots used different zooms and entrances
   remain approximate until checked on campus.

Suggested closing: “The app is intentionally small, works offline and demonstrates
Android XML, Kotlin classes, local data, touch drawing and a basic route algorithm.”
